# Kast Solutions — Корпоративний веб-сайт (ІТ-консалтинг, Кібербезпека та AI)

> Сучасний багатосторінковий корпоративний сайт компанії у сфері IT-консалтингу, штучного інтелекту та кібербезпеки. Розроблений на чистому стеку (HTML5, CSS3, Vanilla JavaScript) з акцентом на високу продуктивність (100 PageSpeed), строгу сучасну типографіку, клієнтську двомовність (i18n), повну адаптивність та інтерактивні UI-ефекти.

---

## 🛠 Технологічний стек

* **HTML5:** Семантична та доступна розмітка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<dialog>`, `<footer>`, WAI-ARIA атрибути).
* **CSS3:**
  * CSS Custom Properties (палітра: глибокий індиго `#0A192F`, графітовий `#1F2937`, лазурний акцент `#0284C7`, білий `#FFFFFF`).
  * Flexbox & CSS Grid для побудови гнучких адаптивних сіток.
  * Плавні трансформації та апаратне прискорення анімацій (`transform: translate3d`, `opacity`).
  * Повна кросплатформна адаптивність (Desktop, Laptop, Tablet, Mobile).
* **Vanilla JavaScript (ES6+):**
  * Чистий JS без важких сторонніх бібліотек та рантайм-залежностей.
  * **Клієнтська інтернаціоналізація (i18n):** миттєве перемикання мов (UK 🇺🇦 / EN 🇬🇧) у реальному часі зі збереженням стану в `localStorage`.
  * Інтерактивний 3D Tilt ефект при наведенні на картки досягнень та нагород.
  * Sticky Header з динамічною зміною стилю при прокручуванні сторінки.
  * Мобільне бургер-меню зі слайд-анімацією та закриттям при кліку поза межами.
  * Модальні діалогові вікна (`<dialog>`) та інтерактивні акордеони.
  * Клієнтська валідація форм, регулярні вирази email та маска форматування номерів телефонів.
* **Fancybox:** Легковагова інтерактивна галерея для перегляду сертифікатів та ліцензій.

## 🚀 Особливості та переваги

1. **Мультимовність (i18n):** Повна підтримка української та англійської мов без перезавантаження сторінки з миттєвим оновленням усього текстового контенту та збереженням вибору користувача.
2. **Максимальна продуктивність:** Жодних важких сторонніх фреймворків чи зайвих залежностей. Чиста статична оптимізація під найвищі показники у Google PageSpeed.
3. **Відносні шляхи (Relative URLs):** Повна сумісність із GitHub Pages та розміщенням у будь-яких підкаталогах веб-сервера.
4. **Доступність (a11y) та SEO:** Семантична розмітка, коректна структура заголовків `h1`–`h6`, `alt`-атрибути для зображень та WAI-ARIA сумісність.
5. **UX & Мікроанімації:** Пропрацьований візуальний відгук на всі дії користувача, плавні переходи станів та 3D Tilt ефекти.

## 💻 Локальний запуск

Сайт є повністю статичним проєктом і не потребує складання або встановлення додаткових пакетів.

### Варіант 1 (Прямий запуск):
Відкрийте файл `index.html` безпосередньо у будь-якому сучасному браузері.

### Варіант 2 (Через локальний веб-сервер):
```bash
# Python 3
python -m http.server 8000

# або через Node.js (npx)
npx serve .
```
Відкрийте у браузері адресу `http://localhost:8000` (або порт, виведений сервером).
